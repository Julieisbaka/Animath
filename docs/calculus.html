Interactive calculus

Make the curve explain itself.

Explore how a mathematical function becomes a renderable scene object. Change the frequency and watch the sampled polyline update in real time.

Live function plot

The graph uses Axes2D coordinate conversion and 300 samples from plotFunction.

1.00

Coordinate space

coordsToPoint(x, y) maps math coordinates into pixels while preserving the conventional upward-positive y-axis.

Sampling

Plots are polylines. Increase samples for smooth curves, or use fewer for responsive controls.

Overlays

Add TangentLine, AreaUnderCurve, or riemannRectangles as siblings in the same scene.

Other domains

Use plotParametric for paths and plotPolar for radial functions such as spirals and roses.

The typed API

const axes = new Axes2D({
  xRange: [-Math.PI * 2, Math.PI * 2],
  yRange: [-1.5, 1.5],
  width: 800,
  height: 420
});
const curve = plotFunction(axes, (x) => Math.sin(x), { samples: 300 });
axes.add(curve);
