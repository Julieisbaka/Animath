Getting started

Install one package and use the framework-agnostic animation core anywhere JavaScript runs.

Install

npm install animath

Builds are available as ESM, CommonJS, and TypeScript declarations.

Core import

import { Circle, SvgRenderer, Timeline, Tween } from 'animath';

Create a scene, attach it to a renderer, and advance a timeline from your application loop.

Optional React

npm install react

Then import UI bindings from animath/react. React remains optional for core-only applications.
