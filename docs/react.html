React adapter

React bindings are published from the same package at animath/react.

Components

AnimathCanvas renders an Animath scene using SVG or Canvas. AnimathPlayer adds play/pause controls and a scrubber.

Hooks

useTimeline connects a timeline to React state, useAnimathScene memoizes scene construction, and useMathSignal provides a small reactive math value.
