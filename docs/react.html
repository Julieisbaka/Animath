Optional React integration

Keep React at the edge.

The core scene graph and timeline stay framework-neutral. The React entrypoint adds lifecycle management, rendering components, and reactive controls when your application needs them.

Why a separate subpath?

Importing animath never requires React. Applications that use React can opt into animath/react without maintaining a second package or duplicating scene primitives.

AnimathCanvas

Renders a scene through SVG or Canvas and optionally advances a timeline in an animation frame loop.

AnimathPlayer

Combines a scene viewport with play/pause controls and a scrubber for lessons and demos.

useTimeline

Connects timeline time, duration, status, play, pause, and seek operations to a React component.

useAnimathScene

Memoizes scene construction so object identity remains stable across React renders.

useMathSignal

A typed state helper for sliders, parameters, and reactive mathematical values.

Typed example

import { AnimathPlayer, useAnimathScene } from 'animath/react';
import { Circle, Timeline, Vector2 } from 'animath';

function Lesson({ timeline }: { timeline: Timeline }) {
  const scene = useAnimathScene(() =>
    new Circle(32).moveTo(new Vector2(120, 120))
  );
  return <AnimathPlayer scene={scene} timeline={timeline} />;
}
