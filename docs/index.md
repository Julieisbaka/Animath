# Animath

> Typed math animation for the web.

Animath is a small, composable toolkit for turning equations, curves, and geometry into interactive visual stories without coupling the core engine to a UI framework.

## Choose a path

- [Getting started](./getting-started.md) — learn the scene, timeline, and renderer model.
- [Calculus lab](./calculus.html) — explore interactive plots.
- [React adapter](./react.md) — add lifecycle-aware React components.
- [API reference](./api.md) — browse the typed public surface.
- [Examples](./examples/) — open the live gallery.

## Highlights

- **Core:** vectors, transforms, timelines, scene objects, and renderers share one typed foundation.
- **Browser:** use inspectable SVG or high-throughput Canvas 2D.
- **Calculus:** plot functions, tangent lines, areas, Riemann sums, and vector fields.
- **Optional React:** use `animath/react` without adding React to the core package.
