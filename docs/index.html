Typed math animation for the web

Build explanations that move.

Animath is a small, composable toolkit for turning equations, curves, and geometry into interactive visual stories, without coupling the core engine to a UI framework.

Read the guide See examples

Core

One coherent API

Vectors, transforms, timelines, scene objects, and renderers share the same typed foundation.

Browser

SVG or Canvas

Inspectable SVG for formulas and diagrams, or Canvas 2D for dense, high-frequency plots.

Calculus

Visual intuition

Plot functions, build tangent lines, shade integrals, render Riemann sums, and explore vector fields.

Optional

React when useful

Use animath/react for lifecycle-aware components without putting React in the core package.
