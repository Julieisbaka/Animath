Animath

Math animation primitives for web applications, interactive lessons, and visual explanations.

Getting started

Install the single package and import the framework-agnostic core:

import { Axes2D, plotFunction, SvgRenderer } from 'animath';

React users can add the optional adapter:

import { AnimathPlayer } from 'animath/react';
