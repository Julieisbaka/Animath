Typed math animation for the web

Build explanations that move.

Animath gives you a small, composable toolkit for turning equations, curves, and geometry into interactive visual stories—without coupling the core engine to a UI framework.

Visual intuition

Plot functions, build tangent lines, shade integrals, render Riemann sums, and explore vector fields.

React when useful

Use animath/react for lifecycle-aware components without putting React in the core package.
