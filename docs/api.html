API reference

The public TypeScript API exported by animath. All signatures below are available from the package root unless noted otherwise.

Math

Vector2 and Vector3

Immutable Cartesian vectors. Common methods include add(other), sub(other), scale(value), length(), normalized(), and lerp(other, amount).

Matrix3

Matrix3.translation(offset: Vector2), Matrix3.rotation(radians: number), and Matrix3.scaling(scale: Vector2) create affine transforms. Use multiply(other: Matrix3) and transformPoint(point: Vector2) to compose and apply them.

CubicBezier

pointAt(t), derivativeAt(t), split(t), and sample(segments) evaluate smooth curves.

Animation

Tween

new Tween({ duration: number, easing?: Easing, onUpdate?: (progress: number) => void }). Progress is clamped to [0, 1].

Timeline

add(animation), play(), pause(), seek(seconds), tick(deltaSeconds), and restart(play?). Seeking is deterministic and safe for scrubbing.

Sequence, Parallel, Spring

Compose animations serially or concurrently, or use a deterministic damped spring track for interactive motion.

Scene and rendering

Mobject is the transformable scene base class. Circle and Polyline are built-in shapes. SvgRenderer produces inspectable vector DOM; Canvas2DRenderer targets high-frequency raster rendering. Both implement Renderer.

Calculus

Axes2D provides coordsToPoint(x, y) and pointToCoords(point). Use plotFunction, plotParametric, plotPolar, TangentLine, AreaUnderCurve, riemannRectangles, and vectorField for visualizations. Invalid ranges, sample counts, and spacing values throw RangeError.

React subpath

Import from animath/react: AnimathCanvas, AnimathPlayer, useTimeline, useAnimathScene, and useMathSignal. React is an optional peer dependency.
