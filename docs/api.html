Public TypeScript API

Reference for building blocks.

Every symbol below is exported from the package root unless marked as part of the optional animath/react subpath.

Math primitives

SymbolTyped surfacePurpose
Vector2, Vector3add, sub, scale, length, normalized, lerpImmutable Cartesian values.
Matrix3translation(Vector2), rotation(number), scaling(Vector2), multiply, transformPoint2D affine transforms.
CubicBezierpointAt(t), derivativeAt(t), split(t), sample(segments)Curves and path sampling.

Animation

TweenOptions = { duration: number; easing?: Easing; onUpdate?: (progress: number) => void }. Tween clamps progress to [0, 1].

Timeline supports add, play, pause, seek(seconds), tick(deltaSeconds), and restart(play?). Sequence, Parallel, and Spring implement the same animation contract.

Scene and rendering

Mobject owns position, rotation, scale, style, children, and parent-aware world transforms. Circle and Polyline are built-in shapes.

Renderer defines resize, beginFrame, renderMobject, and endFrame. SvgRenderer targets inspectable vector DOM; Canvas2DRenderer targets raster throughput.

Calculus

Axes2D exposes coordsToPoint(x: number, y: number): Vector2 and pointToCoords(point: Vector2): Vector2. Plot helpers include plotFunction, plotParametric, plotPolar, TangentLine, AreaUnderCurve, riemannRectangles, and vectorField.

Invalid ranges, dimensions, sample counts, and spacing values throw RangeError.

React subpath

Import AnimathCanvas, AnimathPlayer, useTimeline, useAnimathScene, and useMathSignal from animath/react. React is an optional peer dependency.
